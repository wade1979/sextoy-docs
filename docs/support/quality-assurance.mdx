# Quality Assurance

The product is reviewed through a quality assurance process before shipment. This page summarizes the checks customers can expect at a high level.

## Product Checks

Quality checks may include:

- Hardware assembly review
- Power and connection checks
- Functional control testing
- Visual inspection
- Packaging inspection before shipment

## Software and Web App Checks

The web app is tested for the core user flow, including device token entry, email activation, device connection, and control modes.

## Continuous Improvement

Support feedback, preorder testing, and early user reports may be used to improve future production batches, product documentation, and software releases.
