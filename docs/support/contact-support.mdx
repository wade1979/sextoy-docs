# Contact Support

Contact support for preorder questions, product access issues, warranty requests, return questions, and troubleshooting that is not covered in the guide.

## Before Contacting Support

Please prepare:

- Order number or preorder confirmation
- Email address used for purchase or activation
- Device token or product identifier, if available
- Description of the issue
- Screenshots, photos, or videos that help explain the problem

## Support Requests

Email [customer_service@pulsarfuture.com](mailto:customer_service@pulsarfuture.com) for preorder questions, return and exchange requests, warranty requests, product access issues, and troubleshooting.

Do not ship a product back unless support has provided return instructions.
