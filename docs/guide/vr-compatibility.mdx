# VR Compatibility

Pulsar can be used with VR devices through the browser-based product experience.

## Access Pulsar from a VR Browser

All core product features can be accessed through a browser on a compatible VR device.

Open the Pulsar web app in the VR device browser, enter the device token, and use the same product flows available on desktop or mobile browsers, including device control modes, AI Companion, Video Sync, and support pages.

## Immersive Video Sync

When using the `Video Sync` control mode, Pulsar can support immersive VR playback experiences.

If the user plays a local VR video source or opens an embedded third-party VR video sharing platform such as DeoVR, Video Sync can enter an immersive mode for synchronized playback and device motion.

This allows the user to combine VR video, motion synchronization, and Pulsar's adaptive control system in a single immersive session.

See [Video Sync](/guide/modes/video-sync/) for more details about supported content sources and motion synchronization.
