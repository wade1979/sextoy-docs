# Content Iteration Plan

The documentation site follows an MVP approach. The first version helps users get started; later versions can expand based on product updates and user feedback.

## Version 1

- Quick start
- Product overview
- Device Wi-Fi setup and token
- Device token and email activation
- AI Companion
- Mode overview
- Disconnect and reconnect
- Troubleshooting
- FAQ
- Image and video placeholder components

## Version 2

- Add key screenshots
- Add the quick start walkthrough video
- Split AI Mode, Free Mode, Video Mode, and Meeting Mode into detailed guides
- Expand AI companion creation and usage details

## Version 3

- Add interactive demo components
- Add offline PDF export
- Add partner-facing documentation or multilingual docs
